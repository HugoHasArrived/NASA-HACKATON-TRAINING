# APOLLO 11 — Mission Control

An interactive, responsive Apollo 11 mission website built with Vite and vanilla JavaScript.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`

## Build
Run `npm run build`. Vite creates the production website in `dist/`.

## Deploy to Vercel
1. Push this folder to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Framework preset: **Vite**
4. Build command: `npm run build`
5. Output directory: `dist`
6. Click **Deploy**.

No API keys or environment variables are required.

## Features
- Interactive mission timeline with all major Apollo 11 phases
- Mission elapsed time display and selectable timeline events
- Animated Earth-to-Moon mission path
- Spacecraft status panel and mission data
- Mobile-friendly responsive layout

Historical times are presented in UTC where specified. Some intermediate event times are approximate for storytelling clarity.
