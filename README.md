# Apollo 11 — Astronaut Training Game

A browser-based Apollo 11 learning game built with Vite.

## Run
- `npm install`
- `npm run dev`

## Build
- `npm run build` (output: `dist`)

## Vercel
Framework: Vite  
Build command: `npm run build`  
Output directory: `dist`  
Root directory: `./`

Keep `index.html`, `main.js`, `style.css`, and `package.json` together at the repository root.
