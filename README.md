# Apollo 11 — The Journey
A story-driven first-person 3D educational adventure inspired by Neil Armstrong's life and Apollo 11.

Controls: W/A/S/D to walk, mouse to look, E to interact, Shift to move faster, Esc to release mouse. On touchscreens use the on-screen movement pad and drag-to-look area.

Chapters: Armstrong's early life in Ohio; NASA astronaut selection and Gemini 8; interactive astronaut-training simulations; Saturn V launch and docking; lunar orbit, Eagle landing, moonwalk, science and ascent; rendezvous, Earth return, splashdown, recovery and quarantine.

The game begins at a responsive title screen. Select **BEGIN JOURNEY** to enter the 3D story. Walk toward the glowing interaction markers and press **E** (or tap **USE** on mobile). Story panels pause movement until closed. Training stations are educational simulations, not actual NASA qualification exercises.

This is an independent educational game, not an official NASA product or actual astronaut qualification program.

Run: `npm install` then `npm run dev`
Build: `npm run build`
Vercel: Framework Vite, Build `npm run build`, Output `dist`, Root `./`.
