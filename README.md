# Apollo 11 — The Journey
A story-driven first-person 3D educational adventure inspired by Neil Armstrong's life and Apollo 11.

Controls: W/A/S/D to walk, mouse to look, E to interact, Shift to move faster, Esc to release mouse. On touchscreens use the on-screen movement pad and drag-to-look area.

Chapters: Armstrong's early life on Earth; NASA and test-pilot career; educational astronaut-training stations; Apollo 11 launch; lunar landing and moonwalk; return and splashdown.

This is an independent educational game, not an official NASA product or actual astronaut qualification program.

Run: `npm install` then `npm run dev`
Build: `npm run build`
Vercel: Framework Vite, Build `npm run build`, Output `dist`, Root `./`.
